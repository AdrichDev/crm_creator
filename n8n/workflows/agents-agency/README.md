# Workflows — agents-agency

Carpeta reservada para los workflows del proyecto **agents-agency** que conviven en el
mismo workspace de n8n (`n8n-agents-agency`, docker compose project `3a_estudio`).

Se mantienen aquí, separados de `../crm/`, para saber el origen de cada workflow.
Exportar con: `GET /api/v1/workflows/{id}` → guardar el JSON en esta carpeta.
